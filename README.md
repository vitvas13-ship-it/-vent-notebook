# Блокнот наладчика вентиляции — приложение для Android

Работает полностью без интернета: объекты, системы, точки замера, фото шильдиков,
разделы «Общеобменная» и «Противодымная», импорт паспортов, спецификаций и «Характеристики систем» (PDF/Excel),
паспорта по форме приложения Е СП 73.13330.2016, нормы СП 73 и ГОСТ Р 53300, светлая и тёмная тема.
Всё хранится в памяти телефона внутри приложения.

## Как получить файл APK

### Вариант А — Android Studio (на компьютере)
1. Установите Android Studio: https://developer.android.com/studio
2. Распакуйте этот архив. В Android Studio: **File → Open** → выберите папку `VentNotebook`.
3. Дождитесь окончания синхронизации (внизу полоса «Gradle sync»). Первый раз нужен интернет — скачается 1–2 ГБ.
4. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Справа внизу появится «APK(s) generated» → **locate**. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант Б — без установки программ (через GitHub)
1. Зарегистрируйтесь на https://github.com и создайте новый репозиторий.
2. **Add file → Upload files** → перетащите всё содержимое папки `VentNotebook` (вместе с папками `.github`, `app`, `gradle`) → **Commit**.
3. Вкладка **Actions** → «Собрать APK» → дождитесь зелёной галочки (≈5 минут).
4. Откройте запуск → внизу **Artifacts → VentNotebook-apk** → скачается zip, внутри `app-release.apk`.

Если во вкладке Actions пусто — не загрузилась скрытая папка `.github`. Тогда:
**Actions → set up a workflow yourself** → вставьте текст из файла
`.github/workflows/build.yml` (откройте его Блокнотом) → **Commit**.

## Установка на телефон
1. Перекиньте `.apk` на телефон (кабель, Telegram «Избранное», почта).
2. Откройте файл → разрешите «Установка из неизвестных источников» для приложения, из которого открываете.
3. Установить → на экране появится «Блокнот наладчика».

## Перенос записей из блокнота в Claude
1. В старом блокноте: главный экран → **Сохранить копию** (файл `.json` с фото).
2. Отправьте файл себе на телефон.
3. В приложении: главный экран → **Загрузить из файла** → выберите этот файл.

## Где файлы
Таблица, сводка с фото и резервная копия сохраняются в
**Загрузки / Блокнот наладчика**, и сразу открывается окно «Отправить»
(WhatsApp, Telegram, почта и т.д.).

Таблица Excel (.xlsx) делается прямо в телефоне, интернет не нужен: два листа
«Системы» и «Точки», с фильтрами для сортировки.

## Важно
- Записи живут внутри приложения. При удалении приложения или «Очистить данные» они пропадут —
  периодически делайте **Сохранить копию**.
- Новый APK ставится поверх старого без потери записей: все сборки подписаны одним
  ключом `app/notebook.keystore` — не удаляйте и не меняйте этот файл.
